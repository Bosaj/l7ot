# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest production release of L7OT.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in L7OT, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to the project maintainer: [Oussama EL HADJI](https://www.linkedin.com/in/oussama-el-hadji-388a101b7/) or via private security advisory on GitHub: [Security Advisory Report](https://github.com/Bosaj/l7ot/security/advisories/new).
3. Include detailed steps to reproduce the vulnerability, including browser version, environment, and impact analysis.
4. We acknowledge receipts within 48 hours and work with you to release a patch promptly.
